# MindBridge

MindBridge is an interactive product concept for private, reflective
conversations. It explores how an AI companion can remember user-approved
context, notice recurring patterns, ask a useful follow-up instead of simply
agreeing, and turn a conversation into a gentle reflection and next step.

## What the demo includes

- A working conversation flow with suggested replies
- Visible memory provenance for context carried across conversations
- A lightweight emotional check-in
- A generated inner-landscape reflection
- Pattern, reframe, and two-minute practice cards
- Clear non-clinical and privacy boundaries
- Responsive desktop and mobile layouts

The current version is a frontend product demo with deterministic sample
responses. It does not provide therapy, diagnosis, emergency care, or clinical
advice, and it does not store or transmit real mental-health data.

## Product principles

1. Reflection over agreement
2. User-visible memory over invisible profiling
3. Gentle, concrete next steps over generic reassurance
4. Safety and privacy boundaries before model capability
5. Never present an AI companion as a licensed human professional
